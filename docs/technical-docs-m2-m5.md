**Current scope:** M2 – Prediction Models
**M5 status:** Not implemented yet

## 1. Overview

This document describes the technical implementation and current progress of the M2 and M5 components of the Rank-Based Quantum Backend Recommendation Tool.

The project aims to evaluate and rank quantum computing backends based on their calibration characteristics and the structure of quantum circuits.

The current implementation focuses on M2, which includes two baseline prediction models:

- Model A: Gate-level success probability.
- Model B: Layer-aware quality metric inspired by EPLG.

M5, the web-based backend recommendation interface, has not been implemented yet. Model C, which uses Random Forest regression, is also pending the ground-truth data generated by M3.

## 4. M2 – Prediction Models

### 4.1 Model A – Gate-Level Success Probability

**Source file:** `src/models/model_a.py`

#### Objective

Model A estimates the probability that all gates in a transpiled circuit execute successfully, based on the corresponding gate calibration error rates.

#### Mathematical formulation

For a circuit containing \(N\) gates, the success probability is estimated as:

$$
P_A(C) = \prod_{i=1}^{N}(1-e_i)
$$

Where:

- \(C\): Transpiled quantum circuit.
- \(N\): Number of considered gate instances.
- \(e_i\): Calibration error rate of gate instance \(i\).
- \(P_A(C)\): Estimated gate-only circuit success probability.

A lower gate error rate results in a higher estimated success probability.

#### Calibration matching

Each gate instance is matched against calibration data using:

- Backend name.
- Gate name.
- Physical qubit indices.

The implementation uses the exact physical-qubit tuple to identify the corresponding calibration record.

The following operations are excluded from the calculation:

- `barrier`
- `measure`
- `delay`

The current circuits do not include measurements. Therefore, Model A currently estimates gate-only success probability and does not include readout error.

#### Numerical stability

The implementation uses logarithmic probability accumulation:

$$
\log P_A(C) = \sum_{i=1}^{N}\log(1-e_i)
$$

The final probability is recovered using the exponential function.

This avoids numerical underflow when multiplying many small probabilities.

#### Output

Generated file:

`data/processed/model_a_scores.csv`

Columns:

| Column | Description |
|---|---|
| `circuit_id` | Circuit identifier |
| `backend_name` | Backend identifier |
| `gate_count` | Number of considered gate instances |
| `log_success_probability` | Logarithm of estimated success probability |
| `success_probability` | Estimated gate-only success probability |
| `rank` | Backend ranking for the corresponding circuit |

A higher success probability receives a better rank.

#### Validation

Before running Model A, calibration matching was checked using:

`src/models/check_model_a_inputs.py`

Validation results:

- Calibration records: 112.
- Total gate instances checked: 1,498.
- Missing calibration records: 0.

All considered gate instances had matching calibration data.

Model A successfully generated 40 predictions across 10 circuits and 4 backends.

### 4.2 Model B – Layer-Aware Quality Metric

**Source file:** `src/models/model_b.py`

#### Objective

Model B evaluates the quality of a transpiled circuit by considering its layer structure.

Unlike Model A, which multiplies the success probabilities of all considered gates, Model B evaluates the combined error within each circuit layer and calculates an average layer-level quality indicator.

The metric is inspired by the concept of EPLG but is a custom implementation. It should not be described as the official IBM EPLG metric.

#### Circuit layer extraction

Qiskit's circuit-to-DAG conversion is used to identify circuit layers:

```python
from qiskit.converters import circuit_to_dag

dag = circuit_to_dag(circuit)

for layer in dag.layers():
    ...
```

The implementation extracts gate operations and their physical qubit indices from each layer.

The following operations are excluded:

- `barrier`
- `measure`
- `delay`

Calibration information is matched using the backend name, gate name and physical-qubit tuple.

#### Mathematical formulation

For each layer \(l\), the combined layer error is calculated as:

$$
E_l = 1 - \prod_{g \in L_l}(1-e_g)
$$

Where:

- \(L_l\): Set of gate instances in layer \(l\).
- \(e_g\): Calibration error rate of gate instance \(g\).
- \(E_l\): Estimated combined error of layer \(l\).

The mean layer error is:

$$
\overline{E} = \frac{1}{D}\sum_{l=1}^{D}E_l
$$

Where \(D\) is the number of considered circuit layers.

The Model B score is:

$$
P_B = 1-\overline{E}
$$

A higher score indicates better average layer-level quality.

**Important interpretation:** Model B is an average layer-level quality indicator. It is not the probability that the entire circuit succeeds. Its numerical values should not be directly compared with Model A as if both represented the same physical quantity.

#### Additional output metrics

The implementation also records:

- Mean layer error.
- Maximum layer error.
- Standard deviation of layer errors.
- Mean layer success.

#### Output

Generated file:

`data/processed/model_b_scores.csv`

The output contains 40 predictions, covering 10 circuits and 4 backends.

## 5. Model A and Model B Comparison

The two models were compared using their backend rankings for each circuit.

The comparison script was executed using the generated score files.

### 5.1 Evaluation Metrics

**Exact Rank Agreement**

Measures how many backend entries receive exactly the same rank from both models.

\[
Agreement=\frac{\text{Number of matching ranks}}{\text{Total backend entries}}
\]

**Mean Absolute Rank Difference**

Measures the average absolute difference between the two models' rankings.

\[
MAE_{rank}=\frac{1}{N}\sum_{i=1}^{N}|r_{A,i}-r_{B,i}|
\]

**Top-1 Agreement**

Measures how many circuits have the same highest-ranked backend in both models.

**Spearman Rank Correlation**

Measures the correlation between the two ranking sequences for each circuit.

### 5.2 Experimental Results

| Metric | Result |
|---|---:|
| Number of circuits | 10 |
| Number of backends | 4 |
| Total backend entries | 40 |
| Exact rank agreement | 36/40 (90%) |
| Mean absolute rank difference | 0.1 |
| Top-1 agreement | 10/10 (100%) |
| Circuits with Spearman correlation = 1.0 | 8/10 |

### 5.3 Ranking Differences

Only two circuits produced different rankings between Model A and Model B.

| Circuit | Model A ranking | Model B ranking |
|---|---|---|
| GHZ_5 | Manila > Athens > Lima > Belem | Manila > Lima > Athens > Belem |
| QFT_5 | Lima > Manila > Belem > Athens | Lima > Belem > Manila > Athens |

The remaining eight circuits produced identical backend rankings.

### 5.4 Discussion

The comparison indicates strong ranking agreement between the two baseline models.

Both models selected the same top-ranked backend for all 10 circuits. The differences occurred only between the second- and third-ranked backends for GHZ_5 and QFT_5.

This behavior is consistent with the different scoring approaches:

- Model A considers the accumulated gate-level success probability.
- Model B considers the average layer-level quality.

The results indicate that both approaches produce similar backend preferences for the current dataset, while the layer-aware approach can produce small ranking changes for certain circuit structures.

However, agreement between two models does not establish that either model is more accurate. Independent ground-truth evaluation is required for that conclusion.

## 7. Known Limitations

The current M2 implementation has the following limitations:

1. Model A currently excludes readout error because the current circuits do not include measurement operations.
2. Model A and Model B use calibration error rates and simplified independence assumptions.
3. Model B is a custom EPLG-inspired metric, not the official IBM EPLG implementation.
4. Model B represents average layer-level quality, not whole-circuit success probability.
5. Neither model currently accounts for crosstalk, correlated gate errors or idle-qubit decoherence.
6. The current dataset contains 10 circuits and 4 fake backends, so conclusions should be limited to this experimental scope.
7. Ranking agreement between Model A and Model B does not establish prediction accuracy. Ground-truth evaluation is still needed.
